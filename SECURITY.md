# Security Policy

## Supported Versions

Security updates are provided for the latest release only.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, send an email to: **support+forge@dmomot.com**

Include:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment (if known)
- Any suggested fixes

## Response Timeline

- **Acknowledgment**: within 72 hours
- **Initial assessment**: within 1 week
- **Fix timeline**: depends on severity

## Coordinated Disclosure

We follow coordinated disclosure. We ask that you:

1. Report the issue privately via email
2. Allow reasonable time for a fix before public disclosure
3. Do not exploit the vulnerability beyond what is needed to demonstrate it

We will credit reporters in the release notes unless anonymity is requested.
