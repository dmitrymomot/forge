# core/i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `core/i18n` — a single zero-external-dep package for message catalogs (JSON, precompiled, plural-aware), locale negotiation middleware, and locale-aware number/currency/date/relative formatting, per the approved spec `docs/superpowers/specs/2026-07-17-core-i18n-design.md`.

**Architecture:** Immutable `Bundle` built once at `New` from embedded JSON catalogs; `Locale` is an interned index into a static curated locale table; all hot-path lookups are array indexing over precompiled message segments. Three API layers: package-level ctx one-liners (reading a `Localizer` stamped by middleware or `Bundle.WithLocale`), `Localizer` values for `html/template`, explicit-locale `Bundle` methods. Formatting is append-first internally; every render is total (fail-closed, never panics, never errors).

**Tech Stack:** Go 1.26, stdlib only + `core/money`, `core/ctxkey`. No x/text, no YAML, no logger dep.

## Global Constraints

- Deps allowed: stdlib, `github.com/dmitrymomot/forge/core/money`, `github.com/dmitrymomot/forge/core/ctxkey`. Nothing else (spec).
- All catalogs parsed/compiled at `New`; zero file reads or parsing at render time (spec: "precompiled, no in-flight").
- Runtime rendering never returns errors and never panics: missing key → key echo + miss handler; unresolved ctx → default locale / invariant formatting (spec §Errors).
- Miss handler `func(Miss)` is nil by default — one nil check, zero overhead; never called concurrently-unsafe state (Bundle is immutable).
- Hot-path targets (verified by benchmarks + alloc asserts in Tasks 15–16): `T` ≤ 2 allocs (result string + variadic slice), `Key`-based `T` with no map lookup after warm cache, `Append*` variants 0 allocs — except `AppendCurrency`, whose floor is `money.MinorOK`'s internal decimal allocations (~9 allocs/op, unreachable from this package); it is asserted to add zero allocs on top of that measured baseline. No string concat or map hashing per lookup beyond the single string-key map hit.
- Go 1.26: use `new(expr)` where a pointer-to-value is needed; run `just fmt ./core/i18n/...` after file changes (single-file fmt trips betteralign); `just lint` at the end of every task.
- Tests: black-box in `package i18n_test` for exported behavior; white-box `*_internal_test.go` in `package i18n` only for unexported units. Unit tier only (no Docker, no build tags).
- Commits: conventional style, no Claude attribution lines, no manual line wrapping in bodies.
- Env prefix baked into Config tags: `I18N_DEFAULT_LOCALE`, `I18N_COOKIE_NAME`, `I18N_QUERY_PARAM`.
- v1 curated locale set (16): en, en-GB, de, fr, es, it, pt-BR, pl, cs, uk, ru, nl, tr, ar, ja, zh-CN. Extension is mechanical (add a `localeInfo` row + tests). This narrows the spec's "≈30–40" — Task 14 amends the spec text accordingly.
- Key validation is explicit (`Bundle.ValidateKeys(keys ...Key) error`), not a global registry — a package-global registry would break binaries constructing multiple bundles with different catalogs. Task 14 amends the spec sentence.

```go
// core/i18n/plural.go
package i18n

// PluralCategory is a CLDR plural category. Not every language uses every
// category; unused forms in a catalog fall back along formFallback chains.
type PluralCategory uint8

// CLDR plural categories in canonical order. The numeric values index
// per-message form arrays and must stay dense and stable.
const (
	Zero PluralCategory = iota
	One
	Two
	Few
	Many
	Other

	numCategories = 6
)

var categoryNames = [numCategories]string{"zero", "one", "two", "few", "many", "other"}

// String returns the CLDR category name ("zero" … "other").
func (c PluralCategory) String() string {
	if int(c) < len(categoryNames) {
		return categoryNames[c]
	}
	return "other"
}

// categoryByName maps catalog sub-key names to categories. Returns ok=false
// for non-plural sub-keys.
func categoryByName(s string) (PluralCategory, bool) {
	switch s {
	case "zero":
		return Zero, true
	case "one":
		return One, true
	case "two":
		return Two, true
	case "few":
		return Few, true
	case "many":
		return Many, true
	case "other":
		return Other, true
	}
	return 0, false
}

// PluralRule selects the plural category for an integer count. Rules are
// curated per language in plural_data.go; WithPlural overrides or adds them.
type PluralRule func(n int) PluralCategory

// fallbackChains defines, per category, which forms to try when a catalog
// lacks the selected form (spec: two→few→many→other, few→many→other,
// zero→other, many→other, one→other).
var fallbackChains = [numCategories][]PluralCategory{
	Zero: {Other},
	One:  {Other},
	Two:  {Few, Many, Other},
	Few:  {Many, Other},
	Many: {Other},
}

func formFallback(c PluralCategory) []PluralCategory {
	if int(c) < len(fallbackChains) {
		return fallbackChains[c]
	}
	return nil
}

// pluralProbeNumbers exercises the interesting bands of every curated rule
// (Slavic mod-10/mod-100 windows, Arabic bands, millions).
var pluralProbeNumbers = []int{0, 1, 2, 3, 4, 5, 10, 11, 12, 13, 14, 19, 20, 21, 22, 25, 100, 101, 102, 111, 1000, 1000000}

// SupportedForms reports which plural categories a rule can produce, probed
// over representative counts. Used for load-time catalog validation.
func SupportedForms(rule PluralRule) []PluralCategory {
	var seen [numCategories]bool
	for _, n := range pluralProbeNumbers {
		seen[rule(n)] = true
	}
	out := make([]PluralCategory, 0, numCategories)
	for c := range PluralCategory(numCategories) {
		if seen[c] {
			out = append(out, c)
		}
	}
	return out
}
```

```go
// core/i18n/plural_data.go
package i18n

// Curated CLDR cardinal rules (integer branch only — counts are ints in v1).
// Source: CLDR supplemental plurals; per-language, never family buckets:
// family bucketing is how the old packages broke uk/ru 21 → one.

func absInt(n int) int {
	if n < 0 {
		return -n
	}
	return n
}

// ruleOneOther: en, de, nl, tr.
func ruleOneOther(n int) PluralCategory {
	if absInt(n) == 1 {
		return One
	}
	return Other
}

// ruleOther: ja, zh — no plural distinction.
func ruleOther(int) PluralCategory { return Other }

// ruleFrench: 0..1 → one; whole millions → many.
func ruleFrench(n int) PluralCategory {
	a := absInt(n)
	if a == 0 || a == 1 {
		return One
	}
	if a >= 1000000 && a%1000000 == 0 {
		return Many
	}
	return Other
}

// ruleSpanish: exactly 1 → one; whole millions → many.
func ruleSpanish(n int) PluralCategory {
	a := absInt(n)
	if a == 1 {
		return One
	}
	if a >= 1000000 && a%1000000 == 0 {
		return Many
	}
	return Other
}

// ruleItalianPortuguese shares the Spanish integer branch.
func ruleItalianPortuguese(n int) PluralCategory { return ruleSpanish(n) }

// ruleEastSlavic: uk, ru (and sr/hr/bs when added).
// one:  n%10==1 && n%100!=11
// few:  n%10 in 2..4 && n%100 not in 12..14
// many: everything else (incl. 0)
func ruleEastSlavic(n int) PluralCategory {
	a := absInt(n)
	m10, m100 := a%10, a%100
	switch {
	case m10 == 1 && m100 != 11:
		return One
	case m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14):
		return Few
	default:
		return Many
	}
}

// rulePolish: one only for exactly 1; few for 2..4 windows; many otherwise.
func rulePolish(n int) PluralCategory {
	a := absInt(n)
	if a == 1 {
		return One
	}
	m10, m100 := a%10, a%100
	if m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14) {
		return Few
	}
	return Many
}

// ruleCzech: cs (Slovak shares this shape if a sk row is ever added).
func ruleCzech(n int) PluralCategory {
	a := absInt(n)
	switch {
	case a == 1:
		return One
	case a >= 2 && a <= 4:
		return Few
	default:
		return Other
	}
}

// ruleArabic: full six-category CLDR rule.
func ruleArabic(n int) PluralCategory {
	a := absInt(n)
	switch {
	case a == 0:
		return Zero
	case a == 1:
		return One
	case a == 2:
		return Two
	}
	m100 := a % 100
	switch {
	case m100 >= 3 && m100 <= 10:
		return Few
	case m100 >= 11 && m100 <= 99:
		return Many
	default:
		return Other
	}
}
```

```go
// core/i18n/locale.go
package i18n

import "strings"

// Locale is an interned reference into the curated locale table. The zero
// Locale is invalid; every consumer treats it as "unresolved" and falls back
// to the bundle default. Locale is comparable and pointer-free.
type Locale struct {
	idx uint16 // 1-based table index; 0 = invalid
}

// IsZero reports whether the Locale is the invalid zero value.
func (l Locale) IsZero() bool { return l.idx == 0 }

// info returns the table row, or nil for the zero Locale.
func (l Locale) info() *localeInfo {
	if l.idx == 0 || int(l.idx) > len(localeTable) {
		return nil
	}
	return &localeTable[l.idx-1]
}

// Tag returns the canonical BCP-47-style tag ("uk", "pt-BR"); "" for zero.
func (l Locale) Tag() string {
	if li := l.info(); li != nil {
		return li.tag
	}
	return ""
}

// Lang returns the base language ("pt" for "pt-BR"); "" for zero.
func (l Locale) Lang() string {
	if li := l.info(); li != nil {
		return li.lang
	}
	return ""
}

// String implements fmt.Stringer; identical to Tag.
func (l Locale) String() string { return l.Tag() }

// maxTagLen bounds attacker-controlled tags (cookies, query params) before
// normalization work.
const maxTagLen = 35

// normalizeTag canonicalizes a language tag: trims space, maps '_' to '-',
// keeps at most the first two subtags, lowercases the language and uppercases
// the region. Returns "" for empty or oversized input.
func normalizeTag(s string) string {
	s = strings.TrimSpace(s)
	if s == "" || len(s) > maxTagLen {
		return ""
	}
	s = strings.ReplaceAll(s, "_", "-")
	lang, rest, hasRegion := strings.Cut(s, "-")
	if !hasRegion {
		return strings.ToLower(lang)
	}
	region, _, _ := strings.Cut(rest, "-")
	if region == "" {
		return strings.ToLower(lang)
	}
	return strings.ToLower(lang) + "-" + strings.ToUpper(region)
}

// localeByTag is built once at init from localeTable.
var localeByTag = func() map[string]Locale {
	m := make(map[string]Locale, len(localeTable))
	for i := range localeTable {
		m[localeTable[i].tag] = Locale{idx: uint16(i + 1)}
	}
	return m
}()

// lookupLocale interns a raw tag: exact canonical match first, then the base
// language ("en-AU" → "en"). ok=false when neither is curated.
func lookupLocale(tag string) (Locale, bool) {
	norm := normalizeTag(tag)
	if norm == "" {
		return Locale{}, false
	}
	if l, ok := localeByTag[norm]; ok {
		return l, true
	}
	if lang, _, ok := strings.Cut(norm, "-"); ok {
		if l, ok := localeByTag[lang]; ok {
			return l, true
		}
	}
	return Locale{}, false
}
```

```go
// core/i18n/message.go
package i18n

import (
	"fmt"
	"strconv"
	"strings"
)

// segment is one compiled message part: a literal (arg == "") or a
// placeholder reference.
type segment struct {
	lit string
	arg string
}

// compiledMsg is a message parsed once at construction into segments; render
// is a single pass with no re-parsing.
type compiledMsg struct {
	segs []segment
	size int // total literal length: builder size hint
}

// countArg is the reserved placeholder name TN injects the count under.
const countArg = "count"

// compileMessage parses {{name}} placeholders. Malformed or empty
// placeholders ("{{", "{{}}", "{{a b}}") stay literal text — authoring
// mistakes degrade visibly instead of panicking.
func compileMessage(s string) *compiledMsg {
	m := &compiledMsg{}
	for len(s) > 0 {
		open := strings.Index(s, "{{")
		if open < 0 {
			m.segs = append(m.segs, segment{lit: s})
			m.size += len(s)
			break
		}
		rest := s[open+2:]
		close := strings.Index(rest, "}}")
		if close < 0 {
			m.segs = append(m.segs, segment{lit: s})
			m.size += len(s)
			break
		}
		name := rest[:close]
		if name == "" || strings.ContainsAny(name, " \t{}") {
			// Not a valid placeholder: emit up to and including "{{" as
			// literal and continue scanning after it.
			m.segs = append(m.segs, segment{lit: s[:open+2]})
			m.size += open + 2
			s = s[open+2:]
			continue
		}
		if open > 0 {
			m.segs = append(m.segs, segment{lit: s[:open]})
			m.size += open
		}
		m.segs = append(m.segs, segment{arg: name})
		m.size += len(name) + 8 // rough per-arg size hint
		s = rest[close+2:]
	}
	return m
}

// appendArgValue formats a placeholder value without fmt on the common types.
func appendArgValue(dst []byte, v any) []byte {
	switch x := v.(type) {
	case string:
		return append(dst, x...)
	case int:
		return strconv.AppendInt(dst, int64(x), 10)
	case int64:
		return strconv.AppendInt(dst, x, 10)
	case float64:
		return strconv.AppendFloat(dst, x, 'f', -1, 64)
	case fmt.Stringer:
		return append(dst, x.String()...)
	default:
		return fmt.Append(dst, v)
	}
}

// appendTo renders the message into dst. args are variadic k/v pairs; a
// dangling last element is ignored. When hasCount is set, the reserved
// {{count}} placeholder renders the count unless an explicit "count" pair
// overrides it. Unmatched placeholders render as {{name}} so gaps are
// visible in the UI instead of silently vanishing.
func (m *compiledMsg) appendTo(dst []byte, args []any, count int, hasCount bool) []byte {
	for _, seg := range m.segs {
		if seg.arg == "" {
			dst = append(dst, seg.lit...)
			continue
		}
		if v, ok := lookupArg(args, seg.arg); ok {
			dst = appendArgValue(dst, v)
			continue
		}
		if hasCount && seg.arg == countArg {
			dst = strconv.AppendInt(dst, int64(count), 10)
			continue
		}
		dst = append(dst, "{{"...)
		dst = append(dst, seg.arg...)
		dst = append(dst, "}}"...)
	}
	return dst
}

// render is the string-returning wrapper around appendTo.
func (m *compiledMsg) render(args []any, count int, hasCount bool) string {
	if len(m.segs) == 1 && m.segs[0].arg == "" {
		return m.segs[0].lit // literal-only fast path: zero copies
	}
	return string(m.appendTo(make([]byte, 0, m.size), args, count, hasCount))
}

// lookupArg scans k/v pairs for name. Linear scan: messages have a handful
// of args, so this beats a map allocation.
func lookupArg(args []any, name string) (any, bool) {
	for i := 0; i+1 < len(args); i += 2 {
		if k, ok := args[i].(string); ok && k == name {
			return args[i+1], true
		}
	}
	return nil, false
}
```

```go
// core/i18n/options.go
package i18n

import "io/fs"

// settings accumulates New's options before the immutable Bundle is built.
type settings struct {
	cfg     Config
	sources []fs.FS
	plurals map[string]PluralRule
	formats map[string]FormatSpec
	miss    func(Miss)
}

// Option configures New.
type Option func(*settings) error

// WithConfig replaces the DefaultConfig.
func WithConfig(cfg Config) Option {
	return func(s *settings) error {
		s.cfg = cfg
		return nil
	}
}

// WithMessages adds a catalog source. Layout: {lang}/{namespace}.json under
// the fs.FS root; namespaces become key prefixes. May be given multiple
// times; keys must not collide across sources.
func WithMessages(fsys fs.FS) Option {
	return func(s *settings) error {
		s.sources = append(s.sources, fsys)
		return nil
	}
}

// WithPlural overrides or defines the plural rule for a base language
// (lowercase, e.g. "uk"). Applies to every curated locale of that language.
func WithPlural(lang string, rule PluralRule) Option {
	return func(s *settings) error {
		if rule == nil {
			return ErrNilRule
		}
		if s.plurals == nil {
			s.plurals = make(map[string]PluralRule)
		}
		s.plurals[lang] = rule
		return nil
	}
}

// WithFormatOverride replaces the FormatSpec for one curated locale tag in
// this bundle. Start from DefaultFormat(tag) and patch fields.
func WithFormatOverride(tag string, spec FormatSpec) Option {
	return func(s *settings) error {
		if s.formats == nil {
			s.formats = make(map[string]FormatSpec)
		}
		s.formats[tag] = spec
		return nil
	}
}

// WithMissingHandler sets the miss hook. It is called on runtime lookups
// that fall through to key echo (MissingKey) and once per load-time plural
// probe finding (MissingForm). The handler must be fast and non-blocking —
// it runs on the render path; offload heavy work (DB writes, notifications)
// to a channel or queue.
func WithMissingHandler(fn func(Miss)) Option {
	return func(s *settings) error {
		s.miss = fn
		return nil
	}
}
```

```go
// core/i18n/catalog.go
package i18n

import (
	"encoding/json"
	"fmt"
	"io/fs"
	"path"
	"strings"
)

// entry is one message key's compiled forms. Plain messages occupy the Other
// slot; plural messages fill per-category slots.
type entry struct {
	forms [numCategories]*compiledMsg
}

// rawCatalogs maps canonical locale tag → flattened key → entry.
type rawCatalogs map[string]map[string]*entry

// loadSource walks one fs.FS and merges its catalogs into dst.
func loadSource(dst rawCatalogs, fsys fs.FS) error {
	return fs.WalkDir(fsys, ".", func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			return fmt.Errorf("%w: walking %q: %w", ErrInvalidCatalog, p, err)
		}
		if d.IsDir() || !strings.EqualFold(path.Ext(p), ".json") {
			return nil
		}
		dir := path.Dir(p)
		if dir == "." {
			return fmt.Errorf("%w: %q must be inside a language directory", ErrInvalidCatalog, p)
		}
		tag := normalizeTag(path.Base(dir))
		if _, ok := localeByTag[tag]; !ok {
			return fmt.Errorf("%w: catalog language %q", ErrUnknownLocale, path.Base(dir))
		}
		namespace := strings.TrimSuffix(path.Base(p), path.Ext(p))
		data, err := fs.ReadFile(fsys, p)
		if err != nil {
			return fmt.Errorf("%w: reading %q: %w", ErrInvalidCatalog, p, err)
		}
		var root map[string]any
		if err := json.Unmarshal(data, &root); err != nil {
			return fmt.Errorf("%w: parsing %q: %w", ErrInvalidCatalog, p, err)
		}
		msgs := dst[tag]
		if msgs == nil {
			msgs = make(map[string]*entry)
			dst[tag] = msgs
		}
		return flattenInto(msgs, root, namespace, p)
	})
}

// flattenInto walks nested JSON, flattening keys with dots. A map whose keys
// are all plural category names with string values becomes one plural entry;
// mixing category and non-category keys in one map is an authoring error.
func flattenInto(dst map[string]*entry, node map[string]any, prefix, file string) error {
	if pl, ok, err := asPluralMap(node, prefix, file); err != nil {
		return err
	} else if ok {
		return putEntry(dst, prefix, pl, file)
	}
	for k, v := range node {
		key := prefix + "." + k
		switch x := v.(type) {
		case string:
			e := new(entry)
			e.forms[Other] = compileMessage(x)
			if err := putEntry(dst, key, e, file); err != nil {
				return err
			}
		case map[string]any:
			if err := flattenInto(dst, x, key, file); err != nil {
				return err
			}
		default:
			return fmt.Errorf("%w: %s: key %q: value must be string or object", ErrInvalidCatalog, file, key)
		}
	}
	return nil
}

// asPluralMap detects a plural-forms object. All keys must be category
// names and all values strings; a partial mix is an error, a map with no
// category keys is plain nesting.
func asPluralMap(node map[string]any, key, file string) (*entry, bool, error) {
	found, other := 0, 0
	for k := range node {
		if _, ok := categoryByName(k); ok {
			found++
		} else {
			other++
		}
	}
	if found == 0 {
		return nil, false, nil
	}
	if other > 0 {
		return nil, false, fmt.Errorf("%w: %s: key %q mixes plural forms with nested keys", ErrInvalidCatalog, file, key)
	}
	e := new(entry)
	for k, v := range node {
		s, ok := v.(string)
		if !ok {
			return nil, false, fmt.Errorf("%w: %s: key %q: plural form %q must be a string", ErrInvalidCatalog, file, key, k)
		}
		cat, _ := categoryByName(k)
		e.forms[cat] = compileMessage(s)
	}
	return e, true, nil
}

func putEntry(dst map[string]*entry, key string, e *entry, file string) error {
	if _, exists := dst[key]; exists {
		return fmt.Errorf("%w: %s: %q", ErrDuplicateKey, file, key)
	}
	dst[key] = e
	return nil
}
```

```go
// core/i18n/bundle.go
package i18n

import (
	"fmt"
	"slices"
	"strings"
)

// MissReason classifies a Miss report.
type MissReason uint8

const (
	// MissingKey: a runtime lookup fell through every fallback to key echo.
	MissingKey MissReason = iota
	// MissingForm: load-time probing found a plural entry whose forms don't
	// line up with its language's rule (dead form, or no "other" terminal).
	MissingForm
)

// String names the reason for logs.
func (r MissReason) String() string {
	if r == MissingForm {
		return "missing_form"
	}
	return "missing_key"
}

// Miss is one missing-translation report passed to the WithMissingHandler
// hook.
type Miss struct {
	Locale Locale
	Key    string
	Reason MissReason
}

// Bundle is the immutable i18n engine: catalogs, plural rules, and format
// specs resolved at New. Safe for concurrent use.
type Bundle struct {
	keys    map[string]uint32 // message key → key index
	msgs    [][]*entry        // [localeTableIdx][keyIdx]; nil slice = locale not in catalogs
	chains  [][]uint16        // per localeTableIdx: 0-based table indices to search
	rules   []PluralRule      // per localeTableIdx
	formats []FormatSpec      // per localeTableIdx
	locales []Locale          // supported set, default first then by tag
	def     Locale
	miss    func(Miss)
	cfg     Config
}

// New builds a Bundle from options. All catalog parsing, message
// compilation, and validation happens here; the result never changes.
func New(opts ...Option) (*Bundle, error) {
	s := settings{cfg: DefaultConfig()}
	for _, opt := range opts {
		if err := opt(&s); err != nil {
			return nil, err
		}
	}
	if err := s.cfg.Validate(); err != nil {
		return nil, err
	}

	raw := make(rawCatalogs)
	for _, fsys := range s.sources {
		if err := loadSource(raw, fsys); err != nil {
			return nil, err
		}
	}
	if len(raw) == 0 {
		return nil, fmt.Errorf("%w: no catalogs loaded", ErrInvalidCatalog)
	}

	b := &Bundle{
		cfg:     s.cfg,
		miss:    s.miss,
		msgs:    make([][]*entry, len(localeTable)),
		chains:  make([][]uint16, len(localeTable)),
		rules:   make([]PluralRule, len(localeTable)),
		formats: make([]FormatSpec, len(localeTable)),
	}

	// Key index over the union of all catalog keys, sorted for determinism.
	allKeys := make(map[string]struct{})
	for _, msgs := range raw {
		for k := range msgs {
			allKeys[k] = struct{}{}
		}
	}
	sorted := slices.Sorted(maps.Keys(allKeys))
	b.keys = make(map[string]uint32, len(sorted))
	for i, k := range sorted {
		b.keys[k] = uint32(i)
	}

	// Per-locale message tables.
	for tag, msgs := range raw {
		loc := localeByTag[tag]
		tbl := make([]*entry, len(sorted))
		for k, e := range msgs {
			tbl[b.keys[k]] = e
		}
		b.msgs[loc.idx-1] = tbl
	}

	// Default locale must be supported.
	defLoc, ok := localeByTag[normalizeTag(s.cfg.DefaultLocale)]
	if !ok || b.msgs[defLoc.idx-1] == nil {
		return nil, fmt.Errorf("%w: default locale %q not in catalogs", ErrUnknownLocale, s.cfg.DefaultLocale)
	}
	b.def = defLoc

	// Rules and formats: static table copies, then overrides.
	for i := range localeTable {
		b.rules[i] = localeTable[i].rule
		b.formats[i] = localeTable[i].format
	}
	for lang, rule := range s.plurals {
		found := false
		for i := range localeTable {
			if localeTable[i].lang == lang {
				b.rules[i] = rule
				found = true
			}
		}
		if !found {
			return nil, fmt.Errorf("%w: WithPlural(%q)", ErrUnknownLocale, lang)
		}
	}
	for tag, spec := range s.formats {
		loc, ok := localeByTag[normalizeTag(tag)]
		if !ok {
			return nil, fmt.Errorf("%w: WithFormatOverride(%q)", ErrUnknownLocale, tag)
		}
		b.formats[loc.idx-1] = spec
	}

	// Fallback chains for supported locales: self → base language → default.
	for i := range localeTable {
		if b.msgs[i] == nil {
			continue
		}
		chain := []uint16{uint16(i)}
		if base, ok := localeByTag[localeTable[i].lang]; ok {
			bi := base.idx - 1
			if int(bi) != i && b.msgs[bi] != nil {
				chain = append(chain, bi)
			}
		}
		di := b.def.idx - 1
		if int(di) != i && !slices.Contains(chain, di) {
			chain = append(chain, di)
		}
		b.chains[i] = chain
	}

	// Supported list: default first, then by tag.
	for i := range localeTable {
		if b.msgs[i] != nil {
			b.locales = append(b.locales, Locale{idx: uint16(i + 1)})
		}
	}
	slices.SortFunc(b.locales, func(a, c Locale) int {
		if a == b.def {
			return -1
		}
		if c == b.def {
			return 1
		}
		return strings.Compare(a.Tag(), c.Tag())
	})

	b.probePlurals()
	return b, nil
}

// probePlurals reports catalog/rule mismatches through the miss handler:
// a plural entry without the Other terminal, and defined forms the rule can
// never produce (Zero is exempt — the zero convention).
func (b *Bundle) probePlurals() {
	if b.miss == nil {
		return
	}
	keyByIdx := make([]string, len(b.keys))
	for k, i := range b.keys {
		keyByIdx[i] = k
	}
	for li, tbl := range b.msgs {
		if tbl == nil {
			continue
		}
		supported := SupportedForms(b.rules[li])
		loc := Locale{idx: uint16(li + 1)}
		for ki, e := range tbl {
			if e == nil || !e.isPlural() {
				continue
			}
			if e.forms[Other] == nil {
				b.miss(Miss{Locale: loc, Key: keyByIdx[ki], Reason: MissingForm})
				continue
			}
			for c := range PluralCategory(numCategories) {
				if e.forms[c] != nil && c != Zero && c != Other && !slices.Contains(supported, c) {
					b.miss(Miss{Locale: loc, Key: keyByIdx[ki], Reason: MissingForm})
					break
				}
			}
		}
	}
}

// isPlural reports whether the entry defines any non-Other form.
func (e *entry) isPlural() bool {
	for c := range PluralCategory(numCategories) {
		if c != Other && e.forms[c] != nil {
			return true
		}
	}
	return false
}

// locIdx resolves a locale to its 0-based table index, mapping the zero
// Locale to the default (fail-closed).
func (b *Bundle) locIdx(loc Locale) int {
	if loc.idx == 0 || int(loc.idx) > len(localeTable) {
		return int(b.def.idx) - 1
	}
	return int(loc.idx) - 1
}

// specFor returns the effective FormatSpec for a locale.
func (b *Bundle) specFor(loc Locale) *FormatSpec { return &b.formats[b.locIdx(loc)] }

// ruleFor returns the effective plural rule for a locale.
func (b *Bundle) ruleFor(loc Locale) PluralRule { return b.rules[b.locIdx(loc)] }

// Default returns the bundle's default locale.
func (b *Bundle) Default() Locale { return b.def }

// Locales returns the supported locales, default first.
func (b *Bundle) Locales() []Locale { return slices.Clone(b.locales) }

// Parse interns a tag against this bundle's supported set: exact curated
// match, then base language. Unknown or unsupported tags fail with
// ErrUnknownLocale.
func (b *Bundle) Parse(tag string) (Locale, error) {
	loc, ok := lookupLocale(tag)
	if ok && b.msgs[loc.idx-1] != nil {
		return loc, nil
	}
	if ok {
		// Curated but no catalog: try the base language entry.
		if base, bok := localeByTag[loc.Lang()]; bok && b.msgs[base.idx-1] != nil {
			return base, nil
		}
	}
	return Locale{}, fmt.Errorf("%w: %q", ErrUnknownLocale, tag)
}

// ParseOrDefault is Parse that never fails: empty, malformed, or
// unsupported input yields the default locale.
func (b *Bundle) ParseOrDefault(tag string) Locale {
	if loc, err := b.Parse(tag); err == nil {
		return loc
	}
	return b.def
}

// lookup walks the locale's fallback chain for a key index.
func (b *Bundle) lookup(li int, ki uint32) *entry {
	chain := b.chains[li]
	if chain == nil {
		chain = b.chains[b.def.idx-1]
	}
	for _, ci := range chain {
		if tbl := b.msgs[ci]; tbl != nil {
			if e := tbl[ki]; e != nil {
				return e
			}
		}
	}
	return nil
}

// reportMiss invokes the miss hook if configured.
func (b *Bundle) reportMiss(loc Locale, key string) {
	if b.miss != nil {
		b.miss(Miss{Locale: loc, Key: key, Reason: MissingKey})
	}
}

// msgByIdx resolves the Other-form message for a key index, or nil after
// reporting the miss. Shared by T, AppendT, and TK (Task 6).
func (b *Bundle) msgByIdx(loc Locale, ki uint32, key string) *compiledMsg {
	e := b.lookup(b.locIdx(loc), ki)
	if e == nil || e.forms[Other] == nil {
		b.reportMiss(loc, key)
		return nil
	}
	return e.forms[Other]
}

// T translates key for loc, replacing {{name}} placeholders from variadic
// k/v pairs. Missing translations echo the key (and report the miss).
func (b *Bundle) T(loc Locale, key string, args ...any) string {
	ki, ok := b.keys[key]
	if !ok {
		b.reportMiss(loc, key)
		return key
	}
	if m := b.msgByIdx(loc, ki, key); m != nil {
		return m.render(args, 0, false)
	}
	return key
}

// AppendT is T appending into dst (zero extra allocations).
func (b *Bundle) AppendT(dst []byte, loc Locale, key string, args ...any) []byte {
	ki, ok := b.keys[key]
	if !ok {
		b.reportMiss(loc, key)
		return append(dst, key...)
	}
	if m := b.msgByIdx(loc, ki, key); m != nil {
		return m.appendTo(dst, args, 0, false)
	}
	return append(dst, key...)
}

// TN translates a plural key for count n. Form selection: the explicit
// zero form wins at n == 0 when present; otherwise the locale's CLDR rule
// picks, degrading along the form-fallback chain within each catalog before
// moving down the locale chain. The count renders through {{count}}.
func (b *Bundle) TN(loc Locale, key string, n int, args ...any) string {
	if m := b.pluralMsg(loc, key, n); m != nil {
		return m.render(args, n, true)
	}
	return key
}

// AppendTN is TN appending into dst.
func (b *Bundle) AppendTN(dst []byte, loc Locale, key string, n int, args ...any) []byte {
	if m := b.pluralMsg(loc, key, n); m != nil {
		return m.appendTo(dst, args, n, true)
	}
	return append(dst, key...)
}

// pluralMsg picks the plural form message, or nil after reporting the miss.
func (b *Bundle) pluralMsg(loc Locale, key string, n int) *compiledMsg {
	ki, ok := b.keys[key]
	if !ok {
		b.reportMiss(loc, key)
		return nil
	}
	li := b.locIdx(loc)
	cat := b.rules[li](n)
	chain := b.chains[li]
	if chain == nil {
		chain = b.chains[b.def.idx-1]
	}
	for _, ci := range chain {
		tbl := b.msgs[ci]
		if tbl == nil {
			continue
		}
		e := tbl[ki]
		if e == nil {
			continue
		}
		if n == 0 && e.forms[Zero] != nil {
			return e.forms[Zero]
		}
		if m := e.forms[cat]; m != nil {
			return m
		}
		for _, fc := range formFallback(cat) {
			if m := e.forms[fc]; m != nil {
				return m
			}
		}
	}
	b.reportMiss(loc, key)
	return nil
}

// DefaultFormat returns the curated FormatSpec for a locale tag — the
// starting point for WithFormatOverride patches.
func DefaultFormat(tag string) (FormatSpec, bool) {
	if loc, ok := lookupLocale(tag); ok {
		return loc.info().format, true
	}
	return FormatSpec{}, false
}
```

```go
// core/i18n/key.go
package i18n

import (
	"fmt"
	"sync/atomic"
)

// keyCache pins a resolved index to one bundle. Single-slot: the common case
// is one Bundle per process; a second bundle degrades to a map lookup.
type keyCache struct {
	b   *Bundle
	idx uint32
	ok  bool
}

// Key is a pre-resolvable message-key handle. Declare as package vars via
// NewKey and validate at startup with Bundle.ValidateKeys; TK/TNK skip the
// per-call map hash once the cache is warm.
type Key struct {
	s *keyState
}

type keyState struct {
	cache atomic.Pointer[keyCache]
	path  string
}

// NewKey creates a handle for a dotted message path ("app.title").
func NewKey(path string) Key {
	return Key{s: &keyState{path: path}}
}

// Path returns the dotted message path.
func (k Key) Path() string {
	if k.s == nil {
		return ""
	}
	return k.s.path
}

// resolve returns the key index for b, caching the result per bundle.
func (k Key) resolve(b *Bundle) (uint32, bool) {
	if k.s == nil {
		return 0, false
	}
	if c := k.s.cache.Load(); c != nil && c.b == b {
		return c.idx, c.ok
	}
	idx, ok := b.keys[k.s.path]
	k.s.cache.Store(&keyCache{b: b, idx: idx, ok: ok})
	return idx, ok
}

// ValidateKeys verifies every handle resolves in this bundle's catalogs.
// Call once at startup so typos fail fast instead of echoing in production.
func (b *Bundle) ValidateKeys(keys ...Key) error {
	for _, k := range keys {
		if _, ok := k.resolve(b); !ok {
			return fmt.Errorf("%w: %q", ErrUnknownKey, k.Path())
		}
	}
	return nil
}

// TK is T over a pre-resolved Key handle.
func (b *Bundle) TK(loc Locale, k Key, args ...any) string {
	ki, ok := k.resolve(b)
	if !ok {
		b.reportMiss(loc, k.Path())
		return k.Path()
	}
	if m := b.msgByIdx(loc, ki, k.Path()); m != nil {
		return m.render(args, 0, false)
	}
	return k.Path()
}

// TNK is TN over a pre-resolved Key handle.
func (b *Bundle) TNK(loc Locale, k Key, n int, args ...any) string {
	ki, ok := k.resolve(b)
	if !ok {
		b.reportMiss(loc, k.Path())
		return k.Path()
	}
	if m := b.pluralMsgByIdx(loc, ki, k.Path(), n); m != nil {
		return m.render(args, n, true)
	}
	return k.Path()
}
```

```go
// core/i18n/format.go
package i18n

import (
	"strconv"
	"strings"
)

// appendGroupedDigits writes an unsigned integer digit string with the
// locale's group separator every three digits.
func appendGroupedDigits(dst []byte, digits string, groupSep string) []byte {
	n := len(digits)
	if n <= 3 || groupSep == "" {
		return append(dst, digits...)
	}
	first := n % 3
	if first == 0 {
		first = 3
	}
	dst = append(dst, digits[:first]...)
	for i := first; i < n; i += 3 {
		dst = append(dst, groupSep...)
		dst = append(dst, digits[i:i+3]...)
	}
	return dst
}

// appendFloatSpec renders v with prec fraction digits (trimming trailing
// zeros when trim is set) using the spec's separators. Non-finite values
// render via strconv verbatim.
func appendFloatSpec(dst []byte, v float64, prec int, trim bool, spec *FormatSpec) []byte {
	var buf [40]byte
	raw := strconv.AppendFloat(buf[:0], v, 'f', prec, 64)
	s := string(raw) // stays on the stack: s does not escape

	if strings.ContainsAny(s, "NI") { // NaN, +Inf, -Inf
		return append(dst, s...)
	}
	if s[0] == '-' {
		dst = append(dst, '-')
		s = s[1:]
	}
	intPart, frac, hasFrac := strings.Cut(s, ".")
	dst = appendGroupedDigits(dst, intPart, spec.GroupSep)
	if hasFrac && trim {
		frac = strings.TrimRight(frac, "0")
	}
	if hasFrac && frac != "" {
		dst = append(dst, spec.DecimalSep...)
		dst = append(dst, frac...)
	}
	return dst
}

// Number formats v with the locale's separators, up to two fraction digits
// with trailing zeros trimmed. Use NumberPrec for exact precision.
func (b *Bundle) Number(loc Locale, v float64) string {
	return string(b.AppendNumber(nil, loc, v))
}

// AppendNumber is Number appending into dst.
func (b *Bundle) AppendNumber(dst []byte, loc Locale, v float64) []byte {
	return appendFloatSpec(dst, v, 2, true, b.specFor(loc))
}

// NumberPrec formats v with exactly prec fraction digits.
func (b *Bundle) NumberPrec(loc Locale, v float64, prec int) string {
	return string(b.AppendNumberPrec(nil, loc, v, prec))
}

// AppendNumberPrec is NumberPrec appending into dst.
func (b *Bundle) AppendNumberPrec(dst []byte, loc Locale, v float64, prec int) []byte {

		dst = append(dst, '-')
		s = s[1:]
```

```go
// Currency formats a money value: amount digits and grouping follow the
// locale, symbol and minor units follow the Money's currency — a German
// viewer of a USD price sees "1.234,56 $", never a mislabeled €.
func (b *Bundle) Currency(loc Locale, m money.Money) string {
	return string(b.AppendCurrency(nil, loc, m))
}

// pow10i64 covers ISO-4217 minor units (0..4 in practice).
var pow10i64 = [...]int64{1, 10, 100, 1000, 10000, 100000, 1000000}

// AppendCurrency is Currency appending into dst.
func (b *Bundle) AppendCurrency(dst []byte, loc Locale, m money.Money) []byte {
	spec := b.specFor(loc)
	cur := m.Currency()
	sym := cur.Symbol
	if sym == "" {
		sym = cur.Code
	}

	minor, ok := m.MinorOK()
	if !ok {
		// Amount overflows int64 minor units: render the exact decimal
		// without grouping rather than lying. Rare, cold path.
		return appendCurrencyRaw(dst, m.Amount().String(), sym, spec)
	}

	neg := minor < 0
	if neg {
		minor = -minor
		dst = append(dst, '-')
	}

	d := int(cur.MinorUnits)
	if d < 0 || d >= len(pow10i64) {
		d = 2
	}
	p := pow10i64[d]

	var buf [20]byte
	intDigits := strconv.AppendInt(buf[:0], minor/p, 10)

	if spec.CurrencyBefore {
		dst = append(dst, sym...)
		if spec.CurrencySpace {
			dst = append(dst, ' ')
		}
	}
	dst = appendGroupedDigits(dst, string(intDigits), spec.GroupSep)
	if d > 0 {
		dst = append(dst, spec.DecimalSep...)
		frac := minor % p
		for div := p / 10; div > 0; div /= 10 {
			dst = append(dst, byte('0'+frac/div))
			frac %= div
		}
	}
	if !spec.CurrencyBefore {
		if spec.CurrencySpace {
			dst = append(dst, ' ')
		}
		dst = append(dst, sym...)
	}
	return dst
}

// appendCurrencyRaw renders an untruncatable amount with plain digits.
func appendCurrencyRaw(dst []byte, amount, sym string, spec *FormatSpec) []byte {
	if spec.CurrencyBefore {
		dst = append(dst, sym...)
		if spec.CurrencySpace {
			dst = append(dst, ' ')
		}
		return append(dst, amount...)
	}
	dst = append(dst, amount...)
	if spec.CurrencySpace {
		dst = append(dst, ' ')
	}
	return append(dst, sym...)
}
```

```go
	future := d < 0
	if future {
		d = -d
	}
	if d < time.Minute {
		return append(dst, rel.Now...)
	}

	var unit int
	var n int
	switch {
	case d < time.Hour:
		unit, n = relMinute, int(d/time.Minute)
	case d < 24*time.Hour:
		unit, n = relHour, int(d/time.Hour)
	case d < 7*24*time.Hour:
		unit, n = relDay, int(d/(24*time.Hour))
	case d < 31*24*time.Hour:
		unit, n = relWeek, max(1, int(d/(7*24*time.Hour)))
	case d < 366*24*time.Hour:
		unit, n = relMonth, min(12, max(1, int(d/(30*24*time.Hour))))
	default:
		unit, n = relYear, max(1, int(d/(365*24*time.Hour)))
	}

	units := &rel.Units
	tmpl := rel.Past
	if future {
		tmpl = rel.Future
		if rel.FutureUnits != nil {
			units = rel.FutureUnits
		}
	}

	frag := pickForm(&units[unit], b.ruleFor(loc)(n))
	// Render the unit fragment ({{count}}), then splice it into the
	// direction template ({{d}}). Both are single-occurrence scans.
	var fragBuf [48]byte
	rendered := appendTemplate(fragBuf[:0], frag, "{{count}}", strconv.AppendInt(nil, int64(n), 10))
	return appendTemplate(dst, tmpl, "{{d}}", rendered)
}

// pickForm selects the plural form fragment with form fallback.
func pickForm(forms *[numCategories]string, cat PluralCategory) string {
	if s := forms[cat]; s != "" {
		return s
	}
	for _, fc := range formFallback(cat) {
		if s := forms[fc]; s != "" {
			return s
		}
	}
	return forms[Other]
}

// appendTemplate replaces the first occurrence of placeholder ph in tmpl
// with val, appending to dst.
func appendTemplate(dst []byte, tmpl, ph string, val []byte) []byte {
	if i := strings.Index(tmpl, ph); i >= 0 {
		dst = append(dst, tmpl[:i]...)
		dst = append(dst, val...)
		return append(dst, tmpl[i+len(ph):]...)
	}
	return append(dst, tmpl...)
}
```

Note `strconv.AppendInt(nil, …)` allocates one small slice per call; acceptable for v1 (Relative is not a per-cell hot path like T). Task 16's optimization pass revisits it with benchmark data — a stack `[20]byte` scratch is the known fix if it shows up.

```go
// core/i18n/acceptlang.go
package i18n

import (
	"math"
	"slices"
	"strconv"
	"strings"
)

// maxAcceptLanguageLen caps attacker-controlled header work (DoS hygiene,
// carried over from the previous i18n iterations).
const maxAcceptLanguageLen = 4096

// maxAcceptLanguageTags caps the number of parsed entries.
const maxAcceptLanguageTags = 32

type langQ struct {
	tag      string
	q        float64
	wildcard bool
	order    int
}

// Negotiate picks the best supported locale for an Accept-Language header.
// Tags are honored in quality order (header order breaks ties); a tag
// resolves like Parse (exact curated match, then base language); "*"
// resolves to the bundle default. ok=false when nothing matches.
func (b *Bundle) Negotiate(header string) (Locale, bool) {
	if header == "" {
		return Locale{}, false
	}
	if len(header) > maxAcceptLanguageLen {
		header = header[:maxAcceptLanguageLen]
	}

	var tags []langQ
	order := 0
	for part := range strings.SplitSeq(header, ",") {
		if len(tags) >= maxAcceptLanguageTags {
			break
		}
		part = strings.TrimSpace(part)
		if part == "" {
			continue
		}
		lang, params, _ := strings.Cut(part, ";")
		lang = strings.TrimSpace(lang)
		if lang == "" {
			continue
		}
		q := 1.0
		if params != "" {
			params = strings.TrimSpace(params)
			if v, ok := strings.CutPrefix(params, "q="); ok {
				f, err := strconv.ParseFloat(strings.TrimSpace(v), 64)
				// IsNaN is load-bearing: ParseFloat accepts "NaN", and every
				// NaN comparison is false, so "f < 0 || f > 1" alone would
				// admit q=NaN and poison the sort comparator (non-transitive
				// ordering) — same NaN-gate hole auth/lockout had.
				if err != nil || math.IsNaN(f) || f < 0 || f > 1 {
					continue
				}
				q = f
			}
		}
		if q == 0 {
			continue // q=0 means "not acceptable" (RFC 7231 §5.3.1)
		}
		tags = append(tags, langQ{tag: lang, q: q, wildcard: lang == "*", order: order})
		order++
	}
	if len(tags) == 0 {
		return Locale{}, false
	}

	slices.SortStableFunc(tags, func(a, c langQ) int {
		switch {
		case a.q > c.q:
			return -1
		case a.q < c.q:
			return 1
		default:
			return a.order - c.order
		}
	})

	for _, t := range tags {
		if t.wildcard {
			return b.def, true
		}
		if loc, err := b.Parse(t.tag); err == nil {
			return loc, true
		}
	}
	return Locale{}, false
}
```

```go
// core/i18n/middleware.go
package i18n

import "net/http"

// Resolver extracts a locale from a request. Resolvers run in chain order;
// the first success wins.
type Resolver struct {
	resolve func(*http.Request, *Bundle) (Locale, bool)
	vary    bool // response varies on Accept-Language
}

// FromCookie resolves from a cookie value ("uk", "pt-BR").
func FromCookie(name string) Resolver {
	return Resolver{resolve: func(r *http.Request, b *Bundle) (Locale, bool) {
		c, err := r.Cookie(name)
		if err != nil || c.Value == "" {
			return Locale{}, false
		}
		loc, perr := b.Parse(c.Value)
		return loc, perr == nil
	}}
}

// FromQuery resolves from a query parameter.
func FromQuery(name string) Resolver {
	return Resolver{resolve: func(r *http.Request, b *Bundle) (Locale, bool) {
		v := r.URL.Query().Get(name)
		if v == "" {
			return Locale{}, false
		}
		loc, err := b.Parse(v)
		return loc, err == nil
	}}
}

// FromHeader resolves a single-tag header (e.g. X-Locale).
func FromHeader(name string) Resolver {
	return Resolver{resolve: func(r *http.Request, b *Bundle) (Locale, bool) {
		v := r.Header.Get(name)
		if v == "" {
			return Locale{}, false
		}
		loc, err := b.Parse(v)
		return loc, err == nil
	}}
}

// FromAcceptLanguage negotiates against the Accept-Language header.
func FromAcceptLanguage() Resolver {
	return Resolver{
		vary: true,
		resolve: func(r *http.Request, b *Bundle) (Locale, bool) {
			return b.Negotiate(r.Header.Get("Accept-Language"))
		},
	}
}

// Middleware resolves the request locale through the resolver chain and
// stamps the Localizer into the request context. With no explicit resolvers
// the chain is cookie (Config.CookieName) → query (Config.QueryParam) →
// Accept-Language. Sets Content-Language; appends Vary: Accept-Language
// when the chain negotiates on it. Never writes cookies — persisting the
// user's choice is the application's concern.
func (b *Bundle) Middleware(resolvers ...Resolver) func(http.Handler) http.Handler {
	if len(resolvers) == 0 {
		resolvers = []Resolver{
			FromCookie(b.cfg.CookieName),
			FromQuery(b.cfg.QueryParam),
			FromAcceptLanguage(),
		}
	}
	varies := false
	for _, r := range resolvers {
		if r.vary {
			varies = true
			break
		}
	}
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			loc := b.def
			for _, res := range resolvers {
				if l, ok := res.resolve(r, b); ok {
					loc = l
					break
				}
			}
			if varies {
				w.Header().Add("Vary", "Accept-Language")
			}
			w.Header().Set("Content-Language", loc.Tag())
			next.ServeHTTP(w, r.WithContext(b.WithLocale(r.Context(), loc)))
		})
	}
}
```
