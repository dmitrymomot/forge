# Notes on the candidate optimizations the brief flags:
#
# 1. BenchmarkNoOpRequest (15 allocs/op, 1328 B/op) — the hot path of every
#    authenticated request. It does zero JSON work already: the request never
#    touches a Namespace, so Session.parse/Get/Set never run. The 15 allocs
#    trace to: one store.Load (MemoryStore.cloneRecord — Payload is nil here
#    so this is cheap), one *Session (newSession), one Info (withSession),
#    two ctxkey.With calls each wrapping the context, one *commitWriter, plus
#    the http.Request clone http.HandlerFunc/mux machinery and the header-map
#    allocations httptest.NewRecorder triggers per call. This roughly matches
#    "context values plus the record clone" — no JSON decode/encode appears
#    anywhere in this path.
#
# 2. withSession allocates an Info per request (auth/session/context.go). This
#    is a real, visible allocation on the BenchmarkNoOpRequest path.
#
# 3. Session.parse (auth/session/session.go) always allocates `raw` via
#    make(map[string]json.RawMessage) even when Payload is empty. This shows
#    up on BenchmarkNamespaceSetAndEncode and BenchmarkUnknownNamespacePassthrough,
#    both of which call encode -> parse. BenchmarkNoOpRequest never calls parse
#    at all (no namespace touched), so this fix does not affect it.
